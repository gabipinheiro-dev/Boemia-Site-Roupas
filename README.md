# BOEMIA — Atividade 2 "Estado da Arte"

Página responsiva da loja fictícia de streetwear **BOEMIA**, construída em **HTML, CSS e JavaScript puros** (sem nenhum framework de JS), usando o **Bootstrap 5** como framework de layout/componentes.

## Estrutura de arquivos

```
boemia/
├── index.html        → estrutura da página
├── css/
│   └── style.css      → estilos próprios (cores, tipografia, ajustes visuais sobre o Bootstrap)
├── js/
│   └── main.js         → dados dos produtos + toda a interatividade
└── README.md
```

Bootstrap, Bootstrap Icons e as fontes (Barlow Condensed / Inter) são carregados via **CDN** direto no `<head>` do `index.html`.

## Componentes do Bootstrap utilizados (mínimo de 8 pedido pela atividade)

1. Navbar — menu fixo no topo
2. Offcanvas — menu mobile em tela cheia
3. Carousel — banner principal do hero (3 slides, fade)
4. Cards — categorias, produtos e avaliações
5. Badges/Tags — etiquetas NOVO/SALE/LIMITADO
6. Buttons / Button group — filtros de produto
7. Modal — detalhes do produto
8. Accordion — FAQ
9. Toast — notificações
10. Grid system (Container/Row/Col)
11. Bootstrap Icons

## Publicando no GitHub Pages

1. Suba a pasta `boemia/` para o GitHub.
2. Settings → Pages → escolha a branch/pasta com o `index.html`.
3. Salve — o link público sai em alguns minutos.
